# 课时簿 · 体验课排班与薪资

Vue 3 + Vite 的本机交互预览。当前没有部署到 Vercel、没有上传 GitHub、没有连接 Supabase；数据仅保存在当前浏览器 localStorage，不会在两个运营之间共享。

## 本地启动

```sh
npm install
npm run dev
```

```sh
npm test
npm run build
```

## 已实现

- 老师档案：姓名、性别、科目、时薪、EGP/JOD；不含包月功能。
- 指定日期排班：周五、周六可逐周安排，也可保留固定模板；当天安排优先，仅影响该日期；空安排表示当天不开放，可恢复固定模板和复制上周同日。已录入工资日期须通过每日异常处理。
- 每周排班：同日多个半小时时段，按生效日期建立历史版本；拒绝覆盖已录入工资日期。
- 每日记录：完课总数、临时加时、请假/缺席/其他异常、原因、奖金/罚款/人工调整。
- 明细计算与周/月/日期范围汇总，Excel 汇总和每日明细导出。
- EGP、JOD 各自统计；未录入日期不自动生成工资。
- 示例需主动载入，可清除；本机数据备份下载。

## 已确认规则

所有日期为开罗当地日期，所有 slot 从整点/半点开始，每个 30 分钟。每节课授课 25 分钟，每 slot 全薪是时薪的一半；未完课有效 slot 按 slot 工资的 50% 支付。请假移除的 slot 不产生任何工资或奖励。

EGP 晚间奖励区间为 17:00–21:00。每段连续可用时间的晚间部分分别取完整小时，每小时 100 EGP。例如 17:00–18:30 奖励 100；17:00–17:30 与 19:00–19:30 奖励 0。相邻的时段合并后视为一段连续时间。异常移除时间会打断连续性。JOD 无晚间奖励，但保留未完课 slot 的 50% 补偿。迟到暂不单独自动处理，必要时由运营通过异常扣除 slot 或人工调整金额处理。

用户示例：周日 16:00–21:00，时薪 150 EGP，完课 4 节，工资 300 + 225 + 400 = 925 EGP。

## Excel 导入及课表看板

读取用户提供的工作簿的 `slot` 工作表，仅提取 English、Math、Arabic 三块，分别映射为英语、数学、阿拉伯语。没有读取日期表中的学生记录作为排班，也没有推算完课数。

共 17 位老师（英语 11、数学 3、阿拉伯语 3），157 个非空排班单元格、421 个老师半小时 slot。斜杠和反斜杠都按多老师分隔；连续 slot 合并为时段。按用户确认，C16 的 Hadir ElNagga 合并为 Hadir ElNaggar，C18 的 ara Diaa 合并为 Sara Diaa。保留原始单元格文字和位置供核对。

导入固定模板自 2026-10-18 生效。未提供的性别、时薪、币种保持未提供/待补充，缺时薪或币种时不计算工资。可在老师档案编辑资料，不会覆盖排班。周五周六原表无数据，未生成安排。

导入只执行一次，保留用户已有资料和修改；若同名同科目已存在，则跳过并记录冲突。尚未修改的张老师 925 EGP 演示档案和记录移入 `demoArchive`，保留在数据备份内，不参与导入后的业务看板。

老师课表按老师显示每周可用时间，科目看板按半小时显示可用老师，并支持指定日期与时间快速查找。两者都使用指定日期排班加每日时间异常后的有效 slot，不依赖时薪是否填写。有空仅代表开放，不表示未预约。

## 按开放时长计薪

老师档案新增计薪方式：原有按 slot 完课与补偿，以及按开放时长全额计薪。按开放时长模式中，完课节数仅作统计，基础工资=有效 slot 数÷2×时薪，不另算半薪补偿，不发晚间奖励，人工奖金/扣款照常叠加。请假扣除和临时加时通过相同的有效 slot 规则计算。每日工资、汇总及 Excel 都分别显示时长工资。

按用户确认，Dalia Bassem 一次性设为按开放时长计薪、270 EGP/小时；记录迁移前配置，不覆盖她的排班、每日记录，也不在后续刷新时重复覆盖手动修改。12:00–16:00 是常见时间，未据此自动重写每天的固定排班。

## 中英文切换

页眉和编辑弹窗均可切换中文 / English。界面语言保存在独立的浏览器偏好中，刷新后保留。导航、科目、星期、表单、工资明细、规则、错误提示和 Excel 导出的表头/工作表名跟随所选语言。老师姓名、原始表格文字、异常原因、排班备注及保存的业务字段保持原样。切换语言不会清空正在填写的表单。
